# Mercari Listing OS

個人のメルカリ出品を支援する、ブラウザだけで動くWebアプリです（MVP）。
商品管理・相場分析・利益計算・出品文章の作成・データの入出力を、**ログイン不要・外部API不要・クラウドDB不要**で使えます。
データはすべてブラウザの IndexedDB に保存され、サーバーへは送信しません。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 商品管理 | 複数写真の登録・プレビュー・カバー変更、ブランド／商品名／型番／サイズ／状態／仕入れ値などの記録、下書き・出品中・売却済みのステータス管理、検索・並べ替え・絞り込み |
| 相場分析 | 比較対象の手入力・CSV取込、**売却済み価格と出品価格を区別**、取得日・情報源・状態・サイズ・URLの記録、売却済み5件以上のときだけ分位点・中央値を算出、即売れ／適正／強気の3つの価格案、データ不足時は「相場不明」と表示、計算根拠と比較対象の一覧表示 |
| 利益計算 | 販売価格・手数料率・送料・梱包費・仕入れ値から**手取り金額と純利益を別々に**算出、入力に合わせてすぐ再計算、損益分岐価格、利益率・ROI |
| 出品文章 | タイトル候補3案（40文字以内）、入力済み情報からの説明文下書き、定型文テンプレートの保存・差し込み、コピー。**未入力の情報（真贋・年代・状態など）は推測で補いません** |
| データ | JSONのエクスポート／インポート（写真を含めるか選べる）、相場データのCSV入出力、実データと区別できるデモデータ（読み込み・一括削除）、他ツールと共有できる共通商品ID |

その他: 日本語UI、スマホ対応、ダークモード（自動／ライト／ダーク）。

## 起動方法

Node.js 20 以上（22 で動作確認済み）が必要です。

```bash
npm install
```

開発サーバー:

```bash
npm run dev
```

http://localhost:3000 を開きます。最初は「データ」→「デモデータを読み込む」で操作を試せます。

本番ビルドと起動:

```bash
npm run build && npm start
```

## テスト

型チェック:

```bash
npm run typecheck
```

ユニットテスト（Vitest。利益計算・分位点／価格案・CSV・出品文章・検索／並べ替え・JSON入出力／IndexedDB）:

```bash
npm test
```

ブラウザE2Eテスト（Playwright。デスクトップ版とモバイル版のChromiumで実行。先に `npm run build` が必要）:

```bash
npm run test:e2e
```

型チェック・ユニットテスト・ビルドをまとめて実行:

```bash
npm run check
```

> Playwright の Chromium が未インストールの環境では、先に `npx playwright install chromium` を実行してください。

## 計算方法

### 相場分析（`src/lib/pricing.ts`）

- 価格案の計算には**売却済み価格だけ**を使います。出品価格は「まだ売れていない価格」なので参考値として別に表示し、計算には使いません。
- 絞り込み（取得日の期間・同じ状態のみ）をした後の売却済みデータが **5件未満なら「相場不明」** とし、分位点・中央値・価格案は表示しません。
- 分位点は線形補間で求めます（Excel の `PERCENTILE.INC`、R の type 7 と同じ方式）。
- 価格案:
  - 即売れ = 第1四分位（P25）
  - 適正 = 中央値（P50）
  - 強気 = 第3四分位（P75）
  - 10円単位で四捨五入し、最低300円とします。
- 出品価格の統計値も、5件以上あるときだけ表示します。

### 利益計算（`src/lib/profit.ts`）

```
販売手数料 = floor(販売価格 × 手数料率)        … 1円未満切り捨て
手取り金額 = 販売価格 − 販売手数料 − 送料       … 売上金として受け取る金額
純利益     = 手取り金額 − 梱包費 − 仕入れ値
損益分岐価格 = 純利益が0円以上になる最低の販売価格（整数・円）
```

手数料率の初期値は10%で、商品ごとに変更できます。手数料の端数処理は、実際の規約に合わせて確認してください。

## データ形式

### 共通商品ID

`Item.id` は UUID v4（例: `5b88a472-b5d2-4bc8-810f-871374aa63d4`）です。商品詳細画面に表示され、コピーできます。
JSONエクスポートや相場CSVの `item_id` でもこのIDを使うので、将来 Buy or Pass など他のツールと連携するときの共通キーになります。インポートしても同じIDのまま保たれます。

### JSON エクスポート

```jsonc
{
  "format": "mercari-listing-os",
  "schemaVersion": 1,
  "exportedAt": "2026-11-04T00:00:00.000Z",
  "items": [
    {
      "id": "UUID v4（共通商品ID）",
      "brand": "", "name": "", "modelNumber": "", "size": "",
      "condition": "new | like_new | no_noticeable_damage | slight_damage | damage | poor | unknown",
      "conditionNote": "状態の詳細", "accessories": "付属品",
      "purchasePrice": 1800,           // 円。未入力は null
      "status": "draft | listed | sold",
      "listingPrice": null, "soldPrice": null,
      "memo": "内部メモ",
      "photoIds": ["…"],              // 先頭がカバー写真
      "profit": { "feeRate": 0.1, "shippingCost": 750, "packagingCost": 50 },
      "listingTitle": "", "listingDescription": "",
      "isDemo": false,                 // デモデータなら true
      "createdAt": "ISO 8601", "updatedAt": "ISO 8601"
    }
  ],
  "comparables": [
    {
      "id": "…", "itemId": "共通商品ID",
      "title": "", "price": 3200,
      "priceType": "sold | listed",    // 売却済み価格 / 出品価格
      "observedAt": "YYYY-MM-DD",      // 取得日
      "source": "情報源", "condition": "…", "size": "", "url": "https://…",
      "note": "", "isDemo": false, "createdAt": "ISO 8601"
    }
  ],
  "templates": [{ "id": "…", "name": "", "body": "", "isDemo": false, "createdAt": "…", "updatedAt": "…" }],
  "photos": [{ "id": "…", "itemId": "…", "mimeType": "image/jpeg", "createdAt": "…", "dataUrl": "data:image/jpeg;base64,…" }]
}
```

- `photos` は「写真を含める」にチェックしたときだけ出力されます。
- インポートは**マージ**方式です。同じIDのデータは上書きし、それ以外は追加します。形式が不正なレコードは読み飛ばし、件数を警告として表示します。
- 写真なしのファイルを取り込んでも、すでに保存されている写真は残ります。

### 相場データ CSV

UTF-8（BOMあり／なしどちらも可）、1行目はヘッダーです。

| 列 | 必須 | 内容 |
| --- | --- | --- |
| `item_id` | △ | 共通商品ID。商品画面から取り込む場合は空欄でよい（その商品に紐づきます） |
| `title` | | 比較対象のタイトル |
| `price` | ○ | 正の整数（円）。`3,200`、全角数字、`円` 付きも可 |
| `price_type` | ○ | `sold`（売却済み）/ `listed`（出品中）。`売却済み`・`出品中` も可 |
| `observed_at` | ○ | 取得日 `YYYY-MM-DD`（`YYYY/M/D` も可） |
| `source` | ○ | 情報源（例: `メルカリで目視確認`） |
| `condition` | | `no_noticeable_damage` などのキー、または `目立った傷や汚れなし` などの表示名 |
| `size` | | サイズ |
| `url` | | `http(s)://` で始まるURLのみ |
| `note` | | メモ |

```csv
item_id,title,price,price_type,observed_at,source,condition,size,url,note
,ナイロンジャケット,3200,sold,2026-10-01,メルカリで目視確認,目立った傷や汚れなし,M,https://example.com/item,
```

- 不正な行は取り込まず、行番号と理由を表示します。
- 出力時は、表計算ソフトで数式として実行されるのを防ぐため、`= + - @` で始まるセルの先頭に `'` を付けます（取り込み時に外します）。
- 「データ」画面から全商品分をまとめて取り込む場合、`item_id` が既存の商品と一致しない行は読み飛ばします。

### デモデータ

「データ」→「デモデータを読み込む」で、**架空の**商品3件・相場データ・テンプレートが入ります。

- すべて `isDemo: true` で保存されます。画面では「デモ」バッジが付き、相場データの情報源は `デモ（架空データ）` です。
- 商品名やブランドも架空のもので、実在の成約価格や販売実績ではありません。
- 「デモデータを削除」で、実データを残したままデモデータだけを消せます。

## 制限事項・方針

- **メルカリへのスクレイピングや非公開APIの呼び出しは行いません。** 相場データは、自分で確認した価格を手入力するか、CSVで取り込んでください。
- 実在の成約価格や販売実績は収録していません。デモデータの価格はすべて架空です。
- 価格案は、登録された比較対象から計算した目安にすぎません。売れることを保証するものではありません。データが少ない、または状態やサイズが違うものが混ざると精度が下がります。
- 出品文章は、入力済みの情報を組み立てるだけの仕組み（テンプレート方式）で、AIによる生成ではありません。真贋・年代・状態などは創作しないため、内容は出品前に必ず確認してください。
- データはこのブラウザの IndexedDB にだけ保存されます。ブラウザのデータを消去したり、別の端末・ブラウザを使ったりすると引き継がれません。定期的に JSON でバックアップしてください。プライベートブラウズでは保存されない場合があります。
- 写真は保存容量を抑えるため、長辺1600pxのJPEGに縮小して保存します（小さい画像はそのまま）。1商品あたり最大20枚です。
- 複数のタブで同時に編集すると、後から保存した内容で上書きされます。
- 手数料率や送料は自分で入力する方式です。最新の料金体系は公式情報で確認してください。

## ディレクトリ構成

```
src/
  app/                  画面（Next.js App Router）
    page.tsx            商品一覧（検索・絞り込み・並べ替え）
    items/new/          商品登録
    items/[id]/         商品詳細（基本情報・相場分析・利益計算・出品文章のタブ）
    calculator/         単独で使える利益計算
    templates/          定型文テンプレートの管理
    data/               JSON・CSVの入出力、デモデータ
  components/           UIコンポーネント
  lib/                  ロジック（画面に依存しない純粋関数が中心）
    pricing.ts          相場分析・分位点・価格案
    profit.ts           利益計算・損益分岐価格
    listing.ts          タイトル・説明文の生成
    csv.ts              CSVの読み書き
    exportFormat.ts     JSONエクスポート形式と検証
    normalize.ts        取り込みデータの正規化
    db.ts               IndexedDB（idb）
    demo.ts             デモデータ
tests/
  unit/                 Vitest
  e2e/                  Playwright
```
